# Safe Crystals (NoCrystalBreak) - v1.0.0

![Mod Icon](src/main/resources/assets/nocrystalbreak/icon.png)

**Version:** 1.0.0 
**Minecraft:** 1.21.1 – 1.21.4  
**Requires:** Fabric Loader  

---

## Description

Safe Crystals (NoCrystalBreak) is a lightweight Fabric mod that prevents accidental block breaking when placing End Crystals.  
This early version was simple and fully client-side, designed for safe crystal placement without extra configuration or Mod Menu support.

---

## Features

- Prevents accidental obsidian breaking while holding an End Crystal  
- Stops client-side block breaking animations from interfering with crystal placement  
- Fully client-side and lightweight  

---

## Requirements

- [Fabric Loader](https://fabricmc.net/)  

---

## Installation

1. Install **Fabric Loader** for your Minecraft version  
2. Place `SafeCrystals-<version>.jar` in the `mods` folder  
3. Launch Minecraft with the Fabric profile  

---

## Notes

- No Mod Menu support in these early versions  
- Configuration is minimal and automatic, no UI available
